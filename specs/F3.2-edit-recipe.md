# F3.2 Edit recipe

**Phase** 3 · **Size** M · **Prototype** yes · **Requirements** FR-7 · **Depends on** F3.1, F2.3

## Summary
Users can change any part of a saved recipe. When ingredients or servings change, macros are recalculated on the server.

## Editor
| Field | Control | Validation |
|---|---|---|
| Title | Text | Required, ≤ 80 characters |
| Description | Multi-line text | ≤ 300 characters |
| Servings | Stepper, 1–12 | Changing it asks **Scale ingredients?** (scales every quantity proportionally) or **Just change the number** |
| Prep / cook minutes | Number fields | 0–600 |
| Ingredients | List: drag to reorder, swipe to delete, tap to edit (catalog search from F1.5, quantity, unit, note, optional toggle), **Add ingredient** | At least 1 |
| Steps | List: drag to reorder, swipe to delete, tap to edit text, **Add step** | At least 1, none empty |

## Save
1. RPC `app.update_recipe(id, recipe jsonb)` replaces the scalar fields and the ingredient rows in one transaction, and sets `updated_at`. `source` becomes `edited` for AI and shared recipes; `manual` recipes stay `manual`.
2. If ingredients or servings changed, call `recompute-macros` (F2.3). The detail view shows "Updating nutrition…" until it returns.
3. If the macros call fails, the recipe is still saved. The macros show "Nutrition out of date" with **Retry**.

## Other behavior
- **Cancel** with unsaved changes asks for confirmation: "Discard changes?".
- **Shared recipes:** if `share_token` is set, edits show on the shared page (see F4.1). The save confirmation mentions this the first time.

## Acceptance criteria
- [ ] Every field can be edited and validation errors are shown inline.
- [ ] Scaling servings from 2 to 4 doubles every quantity, and per-serving macros stay about the same.
- [ ] After saving, an AI recipe has `source = 'edited'`, a manual recipe still has `source = 'manual'`, and the macros match a fresh calculation.
- [ ] A failed macros call doesn't lose the edit.

The same editor, started empty, is used to write new recipes (F3.7).
