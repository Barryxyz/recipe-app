# F0.1 Project setup

**Phase** 0 · **Size** S · **Prototype** yes · **Requirements** NFR-3, NFR-5 · **Depends on** none

## Summary
Create the iOS project, the Supabase project and the repo layout so every later feature has a place to land and a way to run locally.

## Scope
- **Repo:** one git repo with `ios/` (Xcode project), `supabase/` (migrations, functions, seed) and `specs/`.
- **iOS app:** SwiftUI, minimum **iOS 17** (needed for SwiftData in F3.6), iPhone only, portrait only.
- **Dependencies (Swift Package Manager):** `supabase-swift`. Nothing else until a feature needs it.
- **Supabase:** the CLI is installed and `supabase init` has been run. `supabase start` runs the stack locally in Docker. The hosted project is on the free tier.
- **Environments:**
  | | Dev | Prod |
  |---|---|---|
  | Supabase | Local (`supabase start`) or a hosted dev project | Hosted prod project (v1 only) |
  | iOS config | `Dev.xcconfig` | `Prod.xcconfig` |

  The Supabase URL and anon key go in the xcconfig, which is fine because the anon key is public. In the prototype, dev and prod are the same hosted project.
- **Secrets:** `ANTHROPIC_API_KEY` exists only as a Supabase function secret (`supabase secrets set`). It is never committed and never sent to the app (NFR-5).
- **App structure:**
  ```
  App/           entry point, environment, routing
  Features/      Pantry/, Scan/, Recipes/, Shopping/, Settings/
  Services/      SupabaseClient, API wrappers per Edge Function
  Models/        Codable DTOs (SwiftData models arrive in F3.6)
  ```

## Acceptance criteria
- [x] The app builds and runs on the developer's iPhone with a free Apple ID.
- [x] The app makes one authenticated call to Supabase and shows the result (a temporary debug screen is fine).
- [ ] `supabase start` and `supabase db reset` work from a clean clone. *(Deferred 2026-11-03: the prototype uses the hosted project only, to skip installing Docker. `supabase db push` to the hosted project replaces this check until local dev is needed.)*
- [x] A test Edge Function deployed to the hosted project can read `ANTHROPIC_API_KEY`, and the key appears nowhere in the repo or the app bundle (`grep` the built `.app`).
- [x] The README lists the setup steps.

## Out of scope
- CI, TestFlight, crash reporting (F5.2, F5.3).
