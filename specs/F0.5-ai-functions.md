# F0.5 AI functions (shared infrastructure)

**Phase** 0 · **Size** M · **Prototype** yes · **Requirements** NFR-5, D3, D5 · **Depends on** F0.1, F0.3

## Summary
A shared module for every Edge Function that calls Claude. It holds the API key server-side, picks models from config, enforces structured output, validates it, retries on a fallback model and logs token usage. F1.2 and F2.2 build their prompts on top of it.

## Module: `supabase/functions/_shared/ai.ts`
- `callModel({ kind, model, system, messages, outputSchema, maxTokens })` returns `{ data, usage, model }`.
  - Gets structured output by forcing a single tool whose `input_schema` is `outputSchema`.
  - Parses the tool input and validates it with **zod**. A parse failure counts as a validation failure.
  - Writes one row to `ai_usage_log` (user, kind, model, tokens) on every call, including failed ones.
  - Has a 60 s timeout. On a 429 or 5xx it retries once after 2 s, then gives up.
- `withFallback(primary, fallback, validate)` runs the primary model, runs `validate()`, and on failure runs the fallback once. If the fallback also fails, it returns the error.
- **Model config:** environment variables, so models can be swapped without code changes (D3).
  | Variable | Default |
  |---|---|
  | `SCAN_MODEL` | `claude-sonnet-5-5` |
  | `RECIPE_MODEL` | `claude-haiku-5-5` |
  | `FALLBACK_MODEL` | `claude-sonnet-5-5` |
  | `ESTIMATE_MODEL` | `claude-haiku-5-5` |
- **Kill switch:** when `AI_ENABLED=false`, every AI function returns 503 `ai_disabled` and the app shows "AI features are temporarily unavailable." This is the emergency stop if spending runs away (D5); it isn't a per-user cap.

## Common request handling (`_shared/http.ts`)
- Verify the Supabase JWT. Unauthenticated requests get 401.
- Reject request bodies over 10 MB with 413.
- Reject accounts without `purchase_verified_at` with 402 `purchase_required` (F0.6). Skipped when `REQUIRE_PURCHASE=false` (prototype).
- Error format: `{ error: { code, message } }`. Codes: `unauthorized`, `purchase_required`, `bad_request`, `ai_disabled`, `ai_failed`, `validation_failed`, `timeout`.
- Never log request bodies, so photos never reach logs (DESIGN §4).

## Nutrition estimate helper
`estimateNutrition(name)` asks `ESTIMATE_MODEL` for a typical per-100 g nutrient profile, saves it on the `ingredients_private` row with `is_estimated = true`, and returns it. F2.3 uses it for custom items that have no nutrition yet.

## Acceptance criteria
- [ ] A test function that calls `callModel` with a toy schema returns typed data and writes an `ai_usage_log` row.
- [ ] A forced validation failure triggers exactly one fallback call. Both calls are logged.
- [ ] Changing `RECIPE_MODEL` with `supabase secrets set` takes effect without redeploying.
- [ ] `AI_ENABLED=false` returns 503 from every AI function.
- [ ] No request body content shows up in the function logs.
