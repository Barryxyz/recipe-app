# F2.1 Recipe request options

**Phase** 2 · **Size** S · **Prototype** yes · **Requirements** FR-5, FR-12 · **Depends on** F1.4, F1.7 · **Next** F2.2

## Summary
A short options sheet the user fills in before generating recipes. The defaults are good enough that tapping straight through to **Generate** works.

## Sheet
| Option | Control | Default |
|---|---|---|
| Servings | Stepper, 1–12 | `user_prefs.default_servings` |
| Max total time | Chips: 15 / 30 / 45 / 60 min / Any | Any |
| Meal | Chips: Breakfast / Lunch / Dinner / Snack / Dessert / Any | Based on time of day (before 11:00 breakfast, 11–15 lunch, after 15 dinner) |
| Cuisine | Chips for 8 common cuisines, plus free text, optional | None |
| Use expiring items first | Toggle | On |
| Only use what I have | Toggle (no missing ingredients allowed) | Off |

- Below the options: "Using 23 items + 6 staples". Tapping it shows the list, where the user can **exclude** items for this request only (e.g. "save the steak").
- **Generate** calls F2.2 and moves to the results screen (F2.4).
- The last options used are remembered locally, except Meal, which always follows the time of day.

## Rules
- With **fewer than 3 active pantry items** (staples not counted), show a warning before generating: "Recipes may need several items you don't have." The user can still continue.
- With an **empty pantry**, show a prompt to add items (Scan / Add manually) instead of Generate.
- With **Only use what I have** on and fewer than 5 items, note: "Recipes may be very simple."

## Request built for F2.2
```json
{ "servings": 2, "max_minutes": 30, "meal": "dinner", "cuisine": "thai",
  "prefer_expiring": true, "only_on_hand": false, "exclude_pantry_item_ids": ["…"] }
```

## Implementation notes (2026-11-09)
Approved during review:
- **Recipes tab:** a bottom tab bar (Pantry / Recipes). The Recipes tab has a "Get recipe ideas" card that opens this sheet; saved recipes are listed below it later (F3.1).
- **Expired items** are left out automatically, with a note ("2 expired items left out"). Staples alone count as an empty pantry.
- **Servings** stepper is 1–12 (prefs allow up to 20; larger values are capped to match F2.2's check).
- **Cuisines:** Italian, Mexican, Chinese, Japanese, Indian, Thai, Mediterranean, American, plus free text.
- Leaving out every item disables Generate with a note.
- Until F2.2 is deployed, Generate shows a summary of the request (placeholder).
- Code: `Features/Recipes/` (`RecipeOptions`, `RecipeOptionsView`, `RecipesView`); tests: `RecipeOptionsTests`.

## Acceptance criteria
- [x] Generate is possible in one tap with the defaults.
- [x] Excluded items are left out of the request.
- [x] The low-pantry warning and empty-pantry prompt work as described. *(unit tests)*
