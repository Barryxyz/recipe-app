# F1.8 History & waste

**Phase** 1 · **Size** S · **Prototype** yes · **Requirements** FR-15 · **Depends on** F1.4, F1.5 · **Added** 2026-11-04 (user request)

## Summary
A history of what the household used up and threw out, with a few simple numbers, so users can see their usage and waste patterns and buy accordingly. Computed from existing pantry data; no AI.

## User stories
- As a user, I can see what I used and what I threw out, newest first.
- As a user, I can see how much I wasted this month and which items I throw out most, so I buy less of them.
- As a user, I can see what I buy most often.
- As a user, I can put back an item I marked used or discarded by mistake.

## Screen
**Entry point:** a clock button in the pantry toolbar (F1.4) opens **History**.

```
┌─────────────────────────────────────┐
│ History                             │
│ ┌─────────────────────────────────┐ │
│ │ November   24 used · 3 thrown out │ │  ← insights card
│ │ Waste: 11%                       │ │
│ │ Thrown out most: spinach (3×)    │ │
│ │ Bought most: milk (6×), eggs (4×)│ │
│ └─────────────────────────────────┘ │
│ [ All | Used | Thrown out ]         │
│ This week                           │
│  Milk        1 l · Fridge   Used  Tue│
│  Spinach     200 g · Fridge Thrown Mon│
│ Last week                           │
│  …                                  │
└─────────────────────────────────────┘
```

- **List:** used and discarded items, newest first by `status_changed_at`, under headers "This week", "Last week", then month names. Each row: name, amount, location, a **Used** (green) or **Thrown out** (red) tag, and the date.
- **Filter:** All / Used / Thrown out.
- **Row actions** (swipe left, matching F1.4):
  - **Put back:** sets the item active again with its original dates, for mistakes.
  - **Buy again:** adds it to the shopping list. Shown once F3.5 exists.
- **Insights card** (current calendar month, device-local dates; tap to switch to the previous month):
  - Items used and thrown out.
  - **Waste rate** = thrown out ÷ (used + thrown out). Hidden when there are fewer than 5 items in the month, to avoid "100% waste" from a single item.
  - **Thrown out most:** top 3 ingredients by count over the last 90 days.
  - **Bought most:** top 5 ingredients by number of times added over the last 90 days.
- **Empty state:** "Nothing here yet. Items you mark Used or Discard show up here."

## Data
- `pantry_items.status_changed_at` (added 2026-11-04): set by a trigger when status changes, cleared when an item goes back to active. Items finished before it existed use `updated_at` as an approximation.
- **List query:** `pantry_items` where `status <> 'active'` and `deleted_at is null`, ordered by `status_changed_at desc`, 50 per page. Index `pantry_items_household_history_idx`.
- **Insights:** one RPC, `app.pantry_insights(month_start date, tz text)`, returning the counts and top lists as JSON. Security invoker, so RLS scopes it to the household. Items are counted per pantry row; batches of the same ingredient count separately.
- No new tables. Soft-deleted rows (Delete = mistake) are excluded everywhere.

## As built (2026-11-04)
- `app.pantry_insights(month_start, tz)` plus `supabase/tests/history_test.sql` (incl. the Oct 31/Nov 1 DST boundary); Swift `HistoryBuckets`/`PantryInsights` with `HistoryTests`. Put back keeps the original expiry (user's choice). Top lists count times, not amounts.

## Acceptance criteria
- [x] Marking an item Used or Discard makes it appear at the top of History with the right tag and date; Undo (F1.4) removes it again.
- [x] The filter shows only used, only thrown out, or both.
- [x] Put back returns the item to the pantry with its original expiry; it disappears from History.
- [x] Insights for a month match a SQL count of the same rows; the waste rate is hidden below 5 items.
- [x] "Thrown out most" and "Bought most" cover the last 90 days and group batches of the same ingredient.
- [x] Another household's history is never visible (RLS test).
- [x] No AI call is made.

## Out of scope
Charts and trends over many months, money spent or wasted (no prices in the data), nutrition eaten. Possible later additions.
