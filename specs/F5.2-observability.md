# F5.2 Observability

**Phase** 5 · **Size** S · **Prototype** events and cost query only · **Requirements** D5 mitigation · **Depends on** F0.5

## Summary
Enough visibility to answer three questions: Is it crashing? Are people using scan or manual entry, and do scans need heavy editing? What is AI costing, and who's driving it?

## Crash reporting
- **Prototype and TestFlight:** Xcode Organizer crash logs plus MetricKit. Free, no SDK.
- **v1:** add the Sentry Cocoa SDK (free tier) if Organizer isn't enough. Strip personal data and never attach ingredient lists.

## Product events
A table `app.events (id, user_id, name, props jsonb, created_at)`. The client inserts in batches. RLS allows insert-only for the user's own `user_id`.

| Event | Props |
|---|---|
| `scan_completed` | location, photos, items_detected |
| `scan_saved` | detected, deleted, edited, added_manually, saved |
| `manual_item_added` | location, is_custom, via (`pantry\|review\|empty_state\|shopping`) |
| `recipes_generated` | count, fallback_used, latency_ms, options |
| `recipe_saved` / `recipe_edited` / `recipe_deleted` | |
| `cooked_this` | items_changed |
| `shopping_items_added` | from (`recipe\|manual`), count |
| `share_created` | |

**Key prototype metrics:**
- **scan edit rate** = (deleted + edited + added_manually) ÷ saved
- **scan vs. manual mix:** `pantry_items.source`
- **recipe save rate** = saved ÷ generated

## AI cost dashboard
- A view `app.ai_cost_daily` joins `ai_usage_log` with a small `app.model_prices` table ($ per 1M input and output tokens for each model).
  - Shows daily cost by kind and model.
  - Shows the top 10 users by cost over 7 days.
- Saved as SQL snippets in the Supabase dashboard. No separate BI tool.
- **Alert (v1):** a daily `pg_cron` job emails the developer (through a Supabase webhook to an email API on its free tier) if yesterday's cost is more than 2× the 7-day average, or more than $X.
- The Anthropic account's monthly spend limit is the final backstop (D5, F5.3).

## Acceptance criteria
- [ ] Every event in the table is emitted at the right moment, as checked in a debug log.
- [ ] The scan edit rate and source mix can be answered with one SQL query each.
- [ ] Daily AI cost from the view matches the Anthropic console within 5%.
- [ ] No photos and no free-text personal data in events or logs.
