# F0.4 Catalog seed

**Phase** 0 · **Size** L (prototype: S) · **Prototype** ~100 hand-seeded items · **Requirements** FR-9 · **Depends on** F0.3

## Summary
Fill `catalog.ingredients` and `catalog.ingredient_nutrients` with the data that matching, manual entry, expiry and macros all depend on.

## Prototype seed (S)
- A hand-curated `supabase/seed/catalog_seed.csv` of about 100 common fridge, freezer and pantry items: produce, dairy, eggs, meats, condiments and staples.
- **Columns:**
  - name, aliases, category, default unit, `grams_per_unit` and/or `density_g_per_ml`
  - shelf life for each location
  - `is_common_staple`, `allergens`
  - nutrients per 100 g (copied from FoodData Central by hand)
- Loaded by `seed.sql` on `supabase db reset`.
- **As built (2026-11-03):** 106 items. `catalog_items.csv` is hand-edited (no nutrients); `build_catalog_seed.py` looks up each item's exact USDA SR Legacy description and writes `catalog_seed.csv` (with `fdc_id` and nutrients) and `load_catalog.sql`, an idempotent upsert keyed by fixed `id`s. Loaded with `supabase db query --remote -f supabase/seed/load_catalog.sql` (no Docker). Perishables get a 1-day pantry life so they don't fall back to F1.6's 30-day default.

## v1 import (L)
1. **Nutrition:** USDA FoodData Central, Foundation Foods plus the SR Legacy subset. Keep generic items (e.g. "egg, whole, raw") and drop branded foods. Target about 2,000–3,000 ingredients.
2. **Names:** turn USDA descriptions into plain names ("Onions, raw" → "onion"). Done by a one-off script with a manual review pass. An LLM can draft the names, but a person reviews the CSV.
3. **Shelf life:** USDA FoodKeeper JSON, mapped by category or name to `shelf_life_fridge/freezer/pantry_days`. Use the middle of FoodKeeper's range.
4. **Aliases:** UK/US variants ("courgette"/"zucchini") and common names ("scallion"/"green onion").
5. **Unit data:** `grams_per_unit` for countable items (egg, onion, apple) and `density_g_per_ml` for liquids.
6. **Allergens:** tag the top 9 allergens (milk, egg, fish, shellfish, tree nuts, peanuts, wheat, soy, sesame) and gluten.
7. **Staples:** salt, pepper, cooking oil, sugar, flour, water and similar get `is_common_staple`.

The import is a repeatable script (`supabase/seed/import_catalog.ts`) that writes a reviewed CSV, so the database is always loaded from the CSV.

## Search function
`catalog.search_ingredients(q text, lim int default 10)` returns `id, name, category, default_unit, score`:
- exact match on name or alias scores 1.0
- prefix match scores 0.9
- otherwise trigram `similarity()`, keeping results ≥ 0.3

Results are ordered by score, then name length. F1.2, F1.5 and F3.5 all use it.

## Acceptance criteria
- [x] The prototype seed loads, and `search_ingredients('scallion')` returns green onion.
- [x] Every seeded item has nutrients and a fridge shelf life. Missing freezer and pantry values are allowed.
- [x] Every item with `default_unit = 'each'` has `grams_per_unit`.
- [ ] Search returns in under 50 ms on the full v1 catalog. *(v1; not measurable on the 106-item prototype seed.)*
